# Комната — онлайн-чат

Простой чат в реальном времени: вводишь имя, попадаешь в общую комнату, видишь историю за последние 30 минут, список участников и системные сообщения «вошёл в чат» / «покинул чат». Выход — закрытие вкладки.

**Стек:** Vue 2 (без сборки), PHP 8.3 + Apache, Redis 7, Server-Sent Events. Всё запускается в Docker.

## Запуск локально

Нужен только [Docker](https://docs.docker.com/get-docker/) с Docker Compose.

```bash
git clone <адрес репозитория> chat
cd chat
docker compose up --build
```

Откройте http://localhost:8089.

Остановить: `Ctrl+C`, затем `docker compose down`. История чата хранится в томе Redis и переживает перезапуск. Чтобы стереть её: `docker compose down -v`.

### Настройки (необязательно)

Скопируйте `.env.example` в `.env` и поменяйте значения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `CHAT_PORT` | `8089` | порт на вашем компьютере |
| `REDIS_PASSWORD` | `chat-dev-password` | пароль Redis (порт наружу не открыт) |
| `COOKIE_SECURE` | `0` | поставьте `1`, если чат стоит за HTTPS |

## Как проверить

1. В первом браузере откройте чат, введите «Юзер 1», отправьте «Привет! 😁».
2. Во втором браузере (или в окне инкогнито: нужны другие cookie) введите «Юзер 2». У обоих справа появится список из двух участников, у Юзера 2 будет та же история.
3. Отправьте «Hello! 😁» от Юзера 2: Юзер 1 увидит сообщение сразу.
4. Закройте вкладку Юзера 2. Через 3–10 секунд у Юзера 1 появится «Юзер 2 покинул чат».

Автотесты (логика, валидация, Redis):

```bash
docker compose exec web php /var/www/tests/run.php
```

## Как устроено

- `public/` — фронтенд (`index.html`, `assets/app.js`, `assets/style.css`) и единая точка входа API `api.php`.
- `src/Chat.php` — логика чата поверх Redis. Вход и выход выполняют Lua-скрипты, поэтому занятость имени проверяется атомарно.
- `docker/` — настройки Apache (заголовки безопасности, лимиты) и PHP.
- `tests/run.php` — тесты без внешних зависимостей.

События идут по SSE (`api.php?action=stream`). При обрыве браузер переподключается сам и получает только пропущенное (`Last-Event-ID`). Если Redis недоступен, интерфейс показывает «Нет связи» и восстанавливается автоматически.

## Безопасность

Сессии (HttpOnly, SameSite=Strict, смена ID при входе), CSRF-токен, проверка имён и текста (невидимые и похожие на чужие имена, bidi-символы), лимиты запросов и соединений, CSP и другие заголовки, Redis с паролем, версии образов закреплены.

## Ограничения

- Каждый SSE-поток занимает процесс Apache prefork, поэтому онлайн не больше 150 человек (`MaxRequestWorkers`). Для большего числа нужен php-fpm + nginx.
- Лимиты по IP считаются по `REMOTE_ADDR`; за reverse-proxy нужно передавать реальный адрес клиента.
- CSP содержит `unsafe-eval`: полная сборка Vue 2 компилирует шаблон из DOM.
- Для публичного запуска обязательно задайте свой `REDIS_PASSWORD`.
